# NSIS Language Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver an installable native NSIS editor plugin.

**Architecture:** Generated lexer/parser and PSI feed a cached semantic model.
Editor services consume the same statements, declarations and include graph.

**Tech Stack:** Kotlin, Gradle Kotlin DSL, JFlex, Grammar-Kit, IntelliJ Platform.

**Spec:** ../specs/2026-11-09-nsis-design.md

- Java 25, branches 262–263, shared platform APIs only.

## Review Focus

- Dollar-escaped quotes and comment markers inside quoted paths remain strings.
- Includes with cyclic or ambiguous declarations terminate and expose all targets.
- Conditional/macro-generated structures do not yield misleading diagnostics.
- Unsaved changes and settings changes invalidate semantic results.
- Malformed files recover for completion and observe cancellation.
